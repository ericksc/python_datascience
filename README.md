# Python para ciencia de datos · Aula Datos

[Explorar el curso](https://ericksc.github.io/python_datascience/)

28 sesiones de 150 minutos, 70 horas y seis badges. El sitio está en `docs/`, publicado mediante GitHub Pages.

## Versión 1.4.0

- Badge 2 alineado con las cuatro partes del Trabajo Grupal I de películas.
- Contenido adicional de Pandas trasladado al badge 3.
- Ejemplos por pasos y salidas estilo Jupyter, sin print en los ejemplos de esos módulos.
- Simulaciones interactivas y notebooks descargables.
- Revisión de secuencia, evaluaciones y requisitos.

Para consultar localmente, abrir `docs/index.html` o servir `docs/` con un servidor HTTP. La página no ejecuta Python ni almacena calificaciones.


## Navegación por páginas

Cada badge tiene cinco tarjetas superiores con páginas independientes: sesiones, ruta, evidencias, reto y materiales. Cada lección de una sesión también tiene un enlace propio.

Consulta [la revisión de coherencia](docs/REVISION_COHERENCIA.md). Para verificar rutas y recursos locales, ejecuta `node scripts/verify_navigation.cjs`.
