# Aula Datos · Curso de Python para ciencia de datos

12 sesiones de 2 h 30 min (30 horas), más 9–12 horas de tareas y 4–6 horas para el proyecto. Nivel inicial.

Abre index.html para consultar el aula sin conexión (las fuentes externas son opcionales). El código se ejecuta en los notebooks, no dentro de la página. Extrae el ZIP antes de usarlo. La autoevaluación web es formativa y no almacena ni envía notas.

## Preparación recomendada
Usa Google Colab: crea o abre un notebook, sube el .ipynb de la sesión y los CSV requeridos al panel Archivos. El entorno es temporal; descarga tu trabajo al terminar. O usa Jupyter local con Python, pandas, numpy y matplotlib instalados. Mantén las carpetas notebooks y datos al mismo nivel. Para Excel, openpyxl es opcional.

## Evaluación propuesta
